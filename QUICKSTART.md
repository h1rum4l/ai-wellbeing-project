# Quick Start Guide

## Running the Application

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Dev Server:**
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:3000`.

## Quick Navigation

- **Real-Time Assessment:** Use the quick scenario presets (High Stress, Medium Stress, Low Stress) in the sidebar or adjust the three sliders.
- **Wellbeing Chat:** Start an offline conversation or ask for help with workloads, sleep, or breathing.
- **Relax & Play:** Try guided breathing with the expanding orb or the 5-4-3-2-1 grounding exercise.
- **Dataset & Batch:** Run batch evaluation across 122 synthetic samples to review accuracy and distribution.
